# 확장 기능 진행표

**최신 결정: 2026-11-04 사용자가 "이동경로 까지만" 진행하고 다른 부가 기능은 진행하지 말라고 요청했습니다. 아래 다른 기능들은 모두 보류이며 이번 작업에서 구현하지 않았습니다. 구글 지도는 하루 경로 표시용 연결 코드만 준비하며, 구글 로그인은 보류입니다.**

2026-11-04 사용자 요청으로 기존 MVP 제외·후속 기능을 추가 범위로 전환합니다. 이전 PRD/TRD의 제외 문구는 원래 MVP의 기록이며 이번 요청을 취소하지 않습니다. 기능마다 코드 구현, 자동 검증, 외부 서비스 연결, 모바일 기기 검증을 구분합니다.

| 기능 | 현재 상태 | 남은 범위 |
| --- | --- | --- |
| 하루 이동 경로 | 본인 전용 API·48시간 암호화 보관·중지/삭제·전경 웹 화면·지점 주변 검색 구현 및 검증. 구글 지도와 경로선 표시는 사용자 확인 완료 | 모바일 백그라운드 수집·실제 GPS 이동·운영 환경 검증 |
| QR 연락 | 구현 대기 | 불투명 공개 토큰·활성/폐기·번호 비노출 연락 요청·소유자 확인 |
| 조건 알림 | 구현 대기 | 검색 조건 저장·신규 후보 감지·중복 알림 방지·수신함·알림 중지 |
| 사용자 차단 | 구현 대기 | 본인 차단 관리·연락/대화 제한·해제, 반환 진행 상태와 충돌하지 않는 정책 |
| 외부 기관 연계 | 구현 대기 | 출처·공식 조회 링크·갱신 시각 표시, 허용된 데이터 제공 방식 확인 |
| 소셜 로그인 | 서비스 선택 확인 중 | 제공사 앱 설정·검증된 콜백·계정 연결·실제 로그인 검증 |
| 운영 관리자 화면 | 구현 대기 | 지정 운영자 권한·신고 접수/처리·접근 기록, 일반 회원 개인정보 무제한 열람 금지 |
| 고급 검색·후보 추천 | 구현 대기 | 추가 필터·추천 근거·공개 정보 기반 후보 정렬 |
| AI 보조 기능 | 요구·서비스 연결 확인 필요 | 후보 추천 등 보조 역할. 물품의 최종 소유 확인을 임의로 자동 승인하지 않음 |
| 실시간 대화 확장 | 구현 대기 | 기존 관계자 권한·반환 후 읽기 전용 규칙을 유지한 새 메시지 갱신 |
| 실제 푸시·문자·이메일 | 기존 제공사 연결 구조만 있음 | 발송 계정·키·수신 동의·실제 기기/주소에서 검증 |
| 운영 배포 및 자동화 | 별도 운영 작업 미완료 | HTTPS·배포 대상·모니터링·백업 정책·CI·장애 복구 검증 |

근거: 초기 기능흐름도 FR-06(QR), FR-08(조건 알림), FR-09(동선), PRD 후속 기능 항목, TRD 보류 기능 항목. 배포 계정, 소셜 앱, 지도 키, 모바일 프론트엔드 없이 외부 연결까지 완료됐다고 표시하지 않습니다.
