# 프론트 작업 프롬프트

아래 양식의 대괄호 부분을 채워 에이전트에 전달한다. 먼저 루트 `AGENTS.md`와 `MissU_Frontend/AGENTS.md`를 읽게 한다. 모든 도구가 AGENTS.md를 자동으로 읽는 것은 아니므로 파일 경로를 명시한다.

## 기능 구현

```text
루트 AGENTS.md와 MissU_Frontend/AGENTS.md를 읽고 작업해줘.
기능: [예: 습득물 공개 상세]
화면 근거: [Figma 링크·노드 또는 첨부 이미지]
구현 범위: [표시할 정보, 버튼 동작, 이동 경로]
데이터: [확정 API 명세 / 모의 데이터만 사용]
완료 기준: [정상·로딩·빈 결과·오류 등 확인할 동작]

기존 코드와 설정을 먼저 확인하고 최소한으로 수정해줘.
요구사항이나 API가 없으면 임의로 확정하지 말고 확인된 범위부터 진행해줘.
변경 내용·효과·실행한 검사·미확인 사항을 마지막에 알려줘.
```

## 버그 수정

```text
루트 AGENTS.md와 MissU_Frontend/AGENTS.md를 읽고 작업해줘.
문제: [현재 현상]
재현: [기기·OS·실행 방식·순서]
기대 동작: [원하는 결과]
자료: [오류 로그·캡처]

재현 가능한 원인을 먼저 좁히고 기존 구조를 유지해 수정해줘.
무관한 리팩터링은 하지 말고 원인·수정 위치·검증 결과를 설명해줘.
```

## 코드 리뷰

```text
루트 AGENTS.md와 MissU_Frontend/AGENTS.md를 읽고 리뷰해줘.
대상: [브랜치·커밋·파일]
기능 의도: [간단한 설명]

지금은 코드를 수정하지 마.
실제 버그·권한·상태 처리·모바일 사용성 문제를 우선 확인하고,
각 지적에 파일 위치·발생 조건·영향·수정 방향을 붙여줘.
문제가 없으면 없다고 말하고 미확인 항목은 별도로 알려줘.
```

## 기기 확인 후 결과 보완

