## 2. 화면 이동 흐름

형식은 `A → B(버튼 이름)`이다. 끝의 대괄호는 근거다. `10.xx`는 팀원 담당 화면이다.

### 시작과 홈

```text
01.01 환영 → 03.01 검색 전(습득물 먼저 찾아보기) [표식][기록]
01.01 환영 → 02.01 로그인(로그인 / 회원가입) [표식][기록]

01.02 홈·비회원 → 03.01 검색 전(습득물 검색하기) [표식][기록]
01.02 홈·비회원 → 10.01 지도(내 근처 습득물 · 보기) [기록]  ※ 표식은 03-A.02 → D9
01.02 홈·비회원 → 03.G 상세(최근 등록된 습득물의 물품 행) [기록]
01.02 홈·비회원 → 10.01(근처 탭) / 01.06(신고 탭) / 01.04(내것 탭) [기록]
01.02 홈·비회원 → ?(헤더 로그인)  확인 필요

01.03 홈·회원 → 03.01 검색 전(습득물 검색하기) [표식][기록]
01.03 홈·회원 → 10.01 지도(내 근처 습득물 · 보기, 근처 탭) [기록]
01.03 홈·회원 → 03.M 상세(물품 행) [기록]
01.03 홈·회원 → 04.01 유형 선택(신고 탭) [기록]
01.03 홈·회원 → 01.05 내역(홍길동 님, 내것 탭) [표식][기록]

01.04 내것 안내 → 02.01 로그인(로그인하고 계속하기) [표식][기록]
01.06 신고 안내 → 02.01 로그인(로그인하고 계속하기) [표식][기록]
```

01.01에서 01.02 홈으로 바로 가는 연결은 없다. 비회원이 홈에 닿는 길은 03.01의 홈 탭뿐인 것으로 보이나 **확인 필요**.

### 검색과 상세

03.03 결과 → 03-A.01 결과 없음(버튼 아님: 결과가 없는 경우) [표식]
03.03 결과 → 03.M 회원 상세(결과 카드, 회원) [표식]
03.03 결과 → 03.G 비회원 상세(결과 카드, 비회원)  표식 없음, 확인 필요
03.03 결과 → ?(다시 검색하기)  확인 필요
