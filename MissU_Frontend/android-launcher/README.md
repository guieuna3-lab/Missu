# 미슈 안드로이드 설치 앱

1.1.0부터 안드로이드 앱이 위치 기록을 맡습니다. 내 하루 이동 경로에서 동의하고 시작하면 화면을 잠가도 기록하며, 알림의 **기록 중지**에서 즉시 위치 수집을 끝냅니다. 계정의 로그인 정보와 전송 대기 중인 좌표는 앱 메모리에만 있습니다. 안드로이드에서 앱을 강제 종료하면 기록도 끝납니다.

1.1.1부터 팀의 운영 웹을 직접 엽니다. 짧은 연결 확인 실패로 APK 안의 예전 화면에 고정되던 경로를 제거했습니다. 화면·사진 처리 변경은 운영 웹 배포로 반영되고, 네트워크 연결 실패 시 다시 시도할 수 있습니다. 이동 경로 기록 서비스와 알림 중지 기능은 유지합니다.

## 안드로이드 APK 다시 만들기

JDK 17, Gradle 8.11.1, Android SDK 플랫폼 36과 Build Tools 35.0.0을 사용합니다. 이 폴더에서 `gradle assembleRelease`를 실행합니다. 웹 화면은 별도로 배포하며 APK에 중복 포함하지 않습니다. 서명 전 APK는 `build/outputs/apk/release/`에 생깁니다.

런처 자체를 바꿀 때는 `build.gradle`의 `versionCode`를 올리고, 기존 릴리스 서명 키로 APK에 서명합니다. 서명 후 `apksigner verify --verbose --print-certs`로 확인합니다. 설치된 앱을 덮어쓸 수 있도록 패키지명 `kr.missu.web`과 서명 키를 유지합니다.

웹과 앱의 연결 정보는 `../public/.well-known/assetlinks.json`에 있습니다. 여기에는 서명 인증서의 공개 SHA-256 지문만 들어갑니다. 서명 키와 비밀번호는 앱 저장소 밖에서 관리합니다.

## 1.2.0 분실 신고 알림

Firebase 프로젝트의 Android 앱 `kr.missu.web`에서 내려받은 `google-services.json`을 이 폴더에 넣고 빌드합니다. 이 파일은 Git에서 제외합니다. 서버 서비스 계정의 비밀키는 APK에 넣지 않습니다. FCM 25.1.3은 기존 Android 6 이상 지원을 유지하기 위해 사용합니다.

로그인 후 내 분실 신고의 **휴대폰 알림 켜기**를 눌러 동의하면 기기 등록 토큰과 무작위 연결값을 인증된 미슈 API에 등록합니다. 푸시에는 연결값·알림 식별자만 전달하며 위치나 분실물 특징을 넣지 않습니다. 로그아웃과 계정 변경 시 연결값을 지우므로 이전 계정의 발송 대기 알림은 기기에서 표시되지 않습니다. 알림을 누르면 미슈의 본인 알림 목록을 엽니다.

앱 권한 거부, Android 강제 종료, 네트워크 연결 상태에 따라 푸시가 늦거나 오지 않을 수 있습니다. 기기 토큰은 다음 로그인/앱 연결 때 갱신합니다. 앱 안 알림 목록은 별도로 DB에 남습니다. iPhone 홈 화면 웹과 기존 APK는 앱 안 알림 목록을 사용할 수 있지만 이 Android FCM 수신 기능은 새 APK 설치가 필요합니다. 기존 위치 기록 알림의 **기록 중지** 동작은 유지합니다.
